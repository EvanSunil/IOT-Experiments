# Experiment 1: LED Blinking Using ESP32

## Aim
To interface an LED with an ESP32 and make it blink at regular intervals.

## Components Required
- ESP32 DevKit V1
- LED
- 220 Ohm Resistor
- Connecting Wires

## Software Used
Wokwi Simulator

## Working Principle
The ESP32 controls the LED through GPIO pin 2. The program alternately sets the pin HIGH and LOW, turning the LED ON and OFF with a delay of 1000 milliseconds.

## Result
The LED was successfully interfaced with ESP32 and made to blink at regular intervals.
